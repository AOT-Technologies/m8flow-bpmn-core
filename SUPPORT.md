# Support

Here's how to get help with m8flow-core.

## Documentation

Start with the [README](README.md) and the [documentation](docs/README.md).
If a feature seems to be missing, check [Limitations](docs/reference/limitations.md).

## Questions, bugs, and feature requests

Search the
[GitHub issues](https://github.com/AOT-Technologies/m8flow-core/issues)
first, because your question may already have an answer. If it doesn't, open
an issue with the
[question, bug report, or feature request template](https://github.com/AOT-Technologies/m8flow-core/issues/new/choose).

GitHub issues are the only public support channel. There's no chat or
mailing list. Maintainers, listed in [MAINTAINERS.md](MAINTAINERS.md), triage
issues on a best-effort basis; there's no guaranteed response time.

Questions about the m8flow platform as a whole, such as the designer, the
backend, or deployment, belong in the
[m8flow repository](https://github.com/AOT-Technologies/m8flow/issues).

## What's planned

See the [roadmap](ROADMAP.md) before you request a feature, because it may
already be planned.

## Security issues

Don't open a public issue. Follow the [security policy](SECURITY.md).
